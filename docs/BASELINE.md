# 长任务基线（BASELINE）

> **本文件的唯一职责**：定义"做什么、不做什么、什么算做到、分几个阶段"。
> **不属于本文件**：技术实现（→ `DESIGN.md`）、参数（→ `PARAMETERS.md`）、今天干什么（→ `TASKS.md`）。
>
> 本文件是**范围契约**。任何范围变更必须先改本文件，再改代码。

| 项 | 值 |
|---|---|
| 基线版本 | v0.2（Demo 优先） |
| 建立日期 | 2026-09-18 |
| 复核时点 | 每个阶段结束时 |

---

## §1 北极星

> **让"带型怎么选"从凭经验变成可算、可看、可比较。**

**最终成功判据**：给定一块地，系统能给出一个可解释的推荐带型，并用可视化证明它比替代方案截获了更多光。

---

## §2 两阶段路线（本基线的核心）

```
阶段一 · Demo              阶段二 · 比赛级产品
─────────────────         ─────────────────────
证明想法可行          ──→   证明科学严谨
跑得起来、看得懂              经得起追问、可复现
允许临时近似                  不允许临时近似
      ▲
      └── 你在这里
```

> **为什么分两段**：阶段一的目标是**尽快验证"这个想法成不成立"**。
> 如果一上来就要求物理严谨，会在验证之前先耗光时间。
> **但阶段一的简化必须登记**，否则它会悄悄变成阶段二的地基——那是灾难。

---

## §3 阶段一 · Demo（当前唯一目标）

### 3.1 目标

做出一段**能证明核心想法**的 demo，并据此判断路线是否可行。

**一句话**：拖动滑块切换**时间与行向** → 光斑肉眼可见地变化 → 大豆/玉米受光比跟着变 → 南北/东西对比成立。

> ⚠️ **2026-09-18 修订**：原表述为"拖动滑块**切换带型**"。
> T-09 实测三个带型（2:3 / 2:4 / 4:4）的 LER 均为 0.9992~0.9994，
> **带型参数（行比 / 带宽 / 株高 / LAI）对结果几乎无影响**（逐项改输入，最大变化 ≤ 1%）；
> 而**时间维度**的信号强度约为带型信号的 **244 倍**。
> 故输入轴改为「**时间 + 行向 + 地点 + 日期**」。
> 这不缩小 demo 效果 —— 它把演示从"看不出差别"改成"差别一眼可见"。
> 决策与证据见 [`TASKS.md`](TASKS.md) §2.3，问题登记见同文件 §3 的 P1。

### 3.2 验收判据（D1–D5，缺一不可）

| # | 判据 | 验证方式 |
|---|---|---|
| **D1** | 能对一个带型输出**光分布剖面图** | 跑出图，横轴为垂直于行向的位置、纵轴为高度 |
| **D2** | 改变**输入（时间 / 行向）**，光斑**肉眼可见**地变化 | 录屏或现场演示；不得靠调色制造差异。⚠️ 原判据写"切换带型"，已按 §3.1 的修订同步（带型参数实测无响应） |
| **D3** | ⭐ **南北 vs 东西并排对比成立** | 同参数、同色标的两张图并排，差异肉眼可辨 |
| **D4** | 出一个 **LER 数字** | 单作基准与间作用同一套算法得出 |
| **D5** | **3 分钟录屏能放** | 成片可播放 |

### 3.4 ⭐ 阶段一的"临时近似"规则

**允许**在阶段一使用简化算法或文献数据插值，条件是**三条同时满足**：

1. 在 `DESIGN.md` 附录 A「临时近似登记表」登记一行：**用什么近似、替代了什么、影响什么结论**
2. 明确写出**替换时点**（进入阶段二前必须替换）
3. 对外演示时**口头说明**"这是原型阶段的近似"

**不允许**：
- ❌ 把近似结果说成模型输出
- ❌ 近似未登记就继续往下做
- ❌ 用近似结果写进对外材料（PPT / 视频字幕 / 答辩稿）

## §5 范围

### ✅ In Scope（两个阶段都做）

1. 带型几何建模（行比、带宽、行向、株高、叶面积分布）
2. 冠层光截获计算
3. 光 → 产量 → LER → 收益的换算链路
4. 光分布可视化（剖面热力图为主）
5. 南北 / 东西行向对比分析

### ❌ Out of Scope（本项目不做）

| # | 不做 | 理由 |
|---|---|---|
| 1 | 自研光线追踪内核 | 有成熟开源模型 |
| 2 | 根系竞争与土壤氮循环 | 复杂度高，非核心 |
| 3 | 病虫害预测、化感作用 | 另一条技术线 |
| 4 | 多年轮作序列优化 | 时间维扩展，留待 v2 |
| 5 | 真实农机自动驾驶对接 | 无硬件条件 |
| 6 | 绝对产量精确预测 | 科学上不成立 |
| 7 | 移动端原生 App | Web 覆盖足够 |

## §6 关键假设（若不成立需重估路线）

| # | 假设 | 若不成立 | 何时验证 |
|---|---|---|---|
| **A1** | 带状间作在平行于行的方向上均匀，可简化为二维剖面 | 需三维建模，工期大增 | 阶段一 |
| **A2** ⚠️ | 成熟开源辐射模型能处理**条带结构（异质冠层）** | 阶段一退回简化算法 + 登记近似；阶段二需重估 | **阶段一 T-01~T-03** |
| **A3** | 关键参数（消光系数、辐射利用效率）可从文献取得可信区间 | 需实测，成本大增 | 阶段二 |
| **A4** | 用户关心的是**相对比较**而非绝对产量 | 产品定位需调整 | 阶段一末用户验证 |
| **A5** | 浏览器端可实时完成单次带型评估 | 交互降级为"点一下等结果" | 阶段二 |

> **当前最高风险：A2。** 所以阶段一的前三个任务全部围绕它展开。

## §7 变更控制

1. 范围变动 → 先改本文件，再改代码
2. 阶段一任务想提前做阶段二内容 → **拒绝**，除非先把对应门槛写进 §4.2 并说明代价
3. 假设 A2 不成立 → 立即停在阶段一，评估是否需要重估技术路线
4. 所有变更记入 `CHANGELOG.md`

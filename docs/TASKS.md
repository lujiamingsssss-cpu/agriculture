| 条带布局几何 | `stripcore/geometry.py` |

| 验收脚本 | `scripts/verify_t02_scene.py` |

### 验收（先写判据，再实现）

- [x] **V1** 单带行比 = 2 玉米 : 4 大豆
- [x] **V2** 从 pyhelios 回读的实测株高：玉米 4 行均 2.600 m、大豆 8 行均 0.700 m，且玉米严格高于大豆
- [x] **V3** 12 行的 u 占位与 `CONVENTIONS.md` §3 逐行一致（容差 1e-3 m，含第 2 带平移）
- [x] **V4** 剖面内光线方向为单位向量，且与 §4.5/§4.6 自洽

> 实跑结果：`uv run python scripts/verify_t02_scene.py` → ✅ 通过，注入 576 个原语。

### 过程中修正的一个错误判据（留档）

V4 最初写成 `dir_w == sin(elev)`，**这是错的**：`CONVENTIONS.md` §4.5 规定
`(dir_u, dir_w) = normalize(perpComp, vertComp)`，是**归一化后**的方向，故 `dir_w`
仅在 `perpComp = 0` 时才等于 1。已改为校验 R1 单位向量 / R2 等效天顶角关系 /
R3 法向投影回归（`stripcore/scenario.py::verify_ray_matches_conventions`）。
**是判据错，不是坐标系错** —— 未调参掩盖。

### 做什么

用 `pyhelios3d` 对 2:4 最小条带场景跑 PAR 波段，输出**逐层**吸收辐射，
并按玉米带 / 大豆带分离；据此对假设 **A2** 给出明确判定。

### 产出

| 产出 | 位置 |
|---|---|
| 辐射计算模块 | `stripcore/radiation.py` |
| 验收脚本 | `scripts/verify_t03_radiation.py` |
| Helios 使用口径登记 | `docs/DESIGN.md` 附录 A.1 |

### 验收（先写判据，再实现）

- [x] **W1** 输出是逐层数组而非仅总量：玉米带 (4,4)、大豆带 (8,4)，层数 = `crop_layers`
- [x] **W2** 单位正确：逐层通量密度 W/m²，并可换算 MJ/m²（换算集中在 `conventions.py`）
- [x] **W3** 玉米带与大豆带已分离：两作物面积与吸收功率独立可查
- [x] **W4** 能量守恒：吸收/截获 = **0.9472** ≤ 1（理论 1−(ρ+τ)⁴ ≈ 0.9995）
- [x] **W5** ⭐ 条带结构可分辨：带中部大豆行（231.27 W/m²）> 边缘行（228.90 W/m²），
      极差 4.835 W/m² 超过重复性噪声下限 2.895 W/m²

> 实跑：`uv run python scripts/verify_t03_radiation.py` → ✅ 通过（W1–W5）。
> 后端 OptiX 8.1；入射 PAR 1000 W/m²；太阳 60°/180°（南北行向）。

### ⭐ A2 判定：**成立**

成熟开源辐射模型（Helios / PyHelios）**能够处理条带结构**：

| 证据 | 数值 |
|---|---|
| 条带内光分布不均（W5） | 单带内大豆行呈对称 U 形：两侧邻接玉米带的行 228.90 W/m²，带中部 231.27 W/m² |
| 差异超出数值噪声 | 极差 4.835 W/m² > 重复性下限 2.895 W/m²（第 1 带 vs 第 2 带同位置行） |
| 空间分离能力（W3） | 玉米带 25.6 m² / 6516.9 W 与大豆带 51.2 m² / 11674.7 W 独立输出 |
| 能量守恒（W4） | 吸收/截获 0.9472 ≤ 1，与 4 层单面叶层理论同量级 |

> ⚠️ **A2 成立的边界**：本判定证明的是"模型能解析条带异质性"，
> **不等于**定性/定量结论已经过验证（那需要判据 C1 与阶段二 P4）。
> 条带效应在当前几何下量级较小（约 2%），因为冠层以水平叶层近似、且太阳在 60° 高角。
> 判据 **C1**（南北 vs 东西）仍待 **T-04** 验证。

### 过程中定位并修正的四个缺陷（留档，均非"调参掩盖"）

| # | 缺陷 | 症状 | 处置 |
|---|---|---|---|
| 1 | `addCollimatedRadiationSource` 方向语义写反 | 水平面吸收 0.000 W/m²，遮蔽效应消失 | 改为传入指向光源的向量；加三重符号自检 |
| 2 | 建波段后未 `disableEmission` | `runBand` 抛能量守恒错误 | 显式禁用 PAR 发射 |
| 3 | 闭合盒几何：竖直面几乎不沉积能量 | 单盒实测总吸收 1904 W，而"各面都工作"应为 2426 W | 弃用闭合盒，改用 `addPatch` 水平叶层 |
| 4 | 每层放上下两片水平面 + `twosided_flag=0` | 直射打到背面只终止不沉积，吸收率掉到 2.6% | 每层只保留朝上的单面 |

> 另修正两处**判据自身**的错误（不是代码错）：
> ① W4 最初用"计算域地面入射"作分母，把重叠叶层的面积和当成投影面积（得 0.4735 的假不守恒）；
> ② 行顶高报告把层厚提到循环外，用玉米层厚算大豆行（得 0.9375 的假株高）。
> 两次都是**判据/报告错**，代码几何与物理没错，未调参掩盖。

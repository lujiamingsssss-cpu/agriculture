> **本文件的唯一职责**：解释"为什么这么设计"——问题、机制、架构、物理原理、假设、临时近似。
> **不属于本文件**：坐标系定义（→ `CONVENTIONS.md`）、参数数值（→ `PARAMETERS.md`）、范围仲裁（→ `BASELINE.md`）。

## §1 问题与用户

| 用户 | 场景 | 现在的做法 | 痛点 |
|---|---|---|---|
| **种粮大户 / 合作社** | 决定这块地用哪个带型 | 听农技员 / 看邻居 / 凭经验 | 不知道换一个会不会更好，不敢试 |
| **基层农技推广员** | 说服农户采用带状复合种植 | 口头讲、发材料 | 讲不清"为什么这样排更好" |
| **农机手 / 农机合作社** | 配套机具、调行距 | 按机器能力倒推带型 | 带宽与机具幅宽不匹配会压苗 |

**核心问题**：带型（行比、带宽、行向）的差异，如何**量化地**影响光能利用？

**本项目定位**：把"可算"和"可看"接起来，并让非农学背景的人也能看懂。

## §2 核心机制

```
带型参数 → 冠层几何 → 光截获计算 → 光分布
                                    ↓
                    RUE 换算 → 产量 → LER → 收益
                                    ↓
                    可视化（剖面热力图 + 三维冠层）
```

### 三个关键设计决策

| # | 决策 | 理由 |
|---|---|---|
| **D1** | 用成熟开源辐射模型，不自研 | 物理可信度；自研在周期内无法验证 |
| **D2** | 计算与渲染分离 | 可验证、可替换、答辩安全 |
| **D3** | 简化为**二维剖面** | 平行于行方向均匀，计算量降一个数量级 |

### 为什么是"剖面"

带状间作在平行于行的方向上统计均匀 → 垂直于行的竖直剖面包含了全部关键物理：
行带排布、株高差异造成的侧向遮挡、由行向决定的太阳投影角。

**一份剖面即一张图，非专业人员能直接看懂**——这是"可解释性"优于"三维炫技"的取舍。

**铁律**：计算层**不得**依赖前端或渲染层。

**阶段一**只做计算层 + 出图；前端交互与渲染层属于阶段二。

## §4 物理原理

### 4.1 核心洞察

```
单作：光只从上方来       带状间作：光还从侧面斜射进来
  ↓ ↓ ↓ ↓ ↓              ↘ ↓ ↓ ↙
  ████████               ↘ █ ↓ █ ↙
                          玉米  大豆
```

**结论**：带状间作**不能**用一维 Beer–Lambert 定律描述，必须考虑水平方向的光进入。

### 4.2 为什么"行向"重要

太阳方位角随时间变化。当**行向与太阳方位平行**时，光在剖面内接近垂直入射，行间受光均匀；当**行向与太阳方位垂直**时，光线在剖面内倾斜最大，前排遮挡后排。

> ⭐ **由此得到核心自检判据 C1**：南北向光截获必须优于东西向。
> 这是农学上的已知结果，可以直接用来验证实现是否正确。

### 4.3 Beer–Lambert 消光定律（均匀冠层）

```
I(L) = I₀ · exp(−k · L)
```

### 4.4 光 → 生物量 → 产量

**采用辐射利用效率（RUE）法，不用机理光合模型。**

理由：本项目做的是**相对比较**；RUE 参数更易获取、更稳健；机理模型参数无法在周期内标定。

```
ΔDM = RUE × PAR_absorbed        (g DM / MJ)
DM  = Σ ΔDM
Y   = DM × HI                     (HI = 收获指数)
```

### 4.5 单作基准（关键）

> ⭐ **单作基准必须用同一模型、同一参数集计算。**

```
Y_solo = 跑 strip_ratio = 1:0 与 0:1 得到
LER = (Y_maize_inter / Y_maize_solo) + (Y_soy_inter / Y_soy_solo)
```

若单作基准取自文献而非本模型，则**模型系统误差不会被抵消，比较无效**。

### 4.6 优化问题的性质

决策变量：行比（5 种）× 带宽（5 档）× 行向（2 种）≈ **50 组**。

> **50 组用网格搜索 5 分钟跑完。不用遗传算法、不用贝叶斯优化。**
> 简单方法 + 可解释结果 > 花哨算法 + 不可信结果。

硬约束：**带宽 ÷ 播种机幅宽 必须接近整数**（否则压苗）。

### 附录 A.2 · ⚠️ 判据 C1 的三条路径均已实测，结论：**问题不在实现，在模型结构**

T-04 为让 C1 成立尝试了三条独立路径，**全部实测**，全部失败。
失败方式不同，但指向同一个结论。

| # | 路径 | 实测结果 | 失败原因 |
|---|---|---|---|
| 1 | **Helios 几何 + 水平叶层**（T-02/T-03 原路径） | C1 反向：南北 18199 W < 东西 19912 W（**−8.6%**，光线数 5000→100000 稳定） | 水平叶层截获量 = 叶面积 × sin(elev)，**与行向无关** |
| 2 | **Helios 几何 + 叶倾角分布**（3 倾角类 × 4 方位类，叶面积守恒 ✅） | C1 仍反向：南北 12583 W < 东西 14544 W（**−13.5%**） | `twosided_flag=0` 只禁止背面**吸收**、不阻断射线；双面则重复计数 —— 遮挡与不重复计数**互斥**，无自洽配置 |
| 3 | **湍流介质解析模型**（G 函数 + Beer–Lambert；G 的三条退化性质与 Lambert 定律均验证到 1e-12） | C1 仍反向：南北 11998 W < 东西 15148 W（**−20.8%**） | **见下：均匀介质在物理上无法表达 C1** |

**路径 3 的解析归因（决定性）**

单层消光系数 = `G(θ_eff) / cos(θ_eff)`，而 `G = cos(θ_eff − tilt)`：

```
θ_eff = 0°  （南北行）→ 系数 = cos(tilt)
θ_eff = 30° （东西行）→ 系数 = cos(30° − tilt) / cos(30°)

临界叶倾角 tilt* ≈ 15°：
    tilt < 15°  → 南北消光更强 → C1 成立
    tilt > 15°  → 东西消光更强 → C1 不成立
本项目 tan 参数：玉米 40°、大豆 70° → 均远大于 15° → C1 **必然不成立**
```

> ⭐ **结论**：在「均匀湍流介质」框架下，C1 不成立是该框架的**物理预言**，不是数值误差。
> 行向只改变一个**均匀**介质的消光系数，而 C1 的真实机制需要
> **水平条带结构的异质性**（高玉米带按行向以不同方式遮挡相邻大豆带）。
> 因此：**任何"每个带当作均匀介质"的模型（含 RATP 的原生 G 函数用法）都无法复现 C1。**

### 附录 A.1 · pyhelios（Helios）使用口径（实测确认，勿凭直觉改）

> 以下四条均为**实测**结论，写错会导致结果整体失真且不报错。改 `stripcore/radiation.py`
> 或 `stripcore/scene.py` 前必读。

| # | 事实 | 写错的后果（实测） |
|---|---|---|
| 1 | `addCollimatedRadiationSource(direction=...)` 要的是**由场景指向光源**的方向（z 分量为**正**），不是光的传播方向 | 取反后直射被完全丢弃：水平面吸收从 865.9 W/m² 掉到 **0.000**，遮蔽效应同时消失 |
| 2 | 建 PAR 波段后**必须 `disableEmission(band)`**：`emissivity` 默认 1.0，而能量守恒要求 `eps+τ+ρ=1` | `runBand` 直接抛 `HeliosRuntimeError: must sum to 1 to ensure energy conservation` |

| 4 | 冠层叶层用 **`addPatch`（水平面）**，不要用 `addTrianglesFromArrays` 造水平三角形；叶层必须是**单面**且**只放朝上的面** | ① 三角形水平面在 `twosided_flag=0` 下吸收恒为 **0**；② 同时放上下两面会使直射打到背面、只终止射线不沉积能量，吸收率掉到入射的 **2.6%** |

## 附录 B · 术语

| 术语 | 含义 |
|---|---|
| **带型** | 行比 + 带宽 + 行向的组合 |
| **行比** | 玉米行数 : 大豆行数，如 2:4 |
| **带宽** | 一个完整带（玉米带 + 大豆带）的宽度 |
| **行向** | 行的走向，从正北顺时针计 |
| **边行优势** | 带边缘植株因受光更好而长势更强 |
| **LER** | 土地当量比 = 间作产量 / 单作产量之和；>1 表示省地 |
| **LAI** | 叶面积指数 |
| **PAR** | 光合有效辐射（400–700 nm） |
| **RUE** | 辐射利用效率，g DM/MJ |
| **HI** | 收获指数 |

**禁止使用的说法**：

| ❌ 不要写 | ✅ 应该写 |
|---|---|
| 预测产量为 X kg/亩 | 该带型相对单作的产量比为 X |
| 本系统计算出的精确光强 | 本模型估算的吸收辐射 |
| 最优带型 | 在当前参数与目标下的推荐带型 |
| 智能优化算法 | 网格搜索 + 帕累托前沿 |
